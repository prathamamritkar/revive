## Bounded Context Specifications

### 1. Telemetry & Classifier Context ([src/classifier.py](./src/classifier.py))
- **Domain Responsibilities**: Parsing failure error codes, bank CBS health diagnosis, LLM semantic fallback reasoning.
- **Published Language**: `AIIntentResponse` (`classification`, `confidence`, `evidence_source`, `evidence_payload`).
- **Downstream Consumers**: Policy Orchestration Context.

### 2. Policy Orchestration Context ([src/orchestrator.py](./src/orchestrator.py))
- **Domain Responsibilities**: TRAI IST chrono-gate bounds, Promise-to-Pay (PTP) freeze, MDP net-yield stopping rules, ExecutionMode governance (`AGENTIC` vs `MANUAL`), SSOT state store, deterministic decision replay (`replay_event`).
- **Upstream Dependencies**: Telemetry & Classifier Context (`AIIntentResponse`).
- **Published Language**: `RecoveryAction`, `AgenticDecisionTrace`, `DispatchRequest`.

### 3. Sentinel Dispatcher Context ([src/dispatcher.py](./src/dispatcher.py))
- **Domain Responsibilities**: Multi-channel delivery (WhatsApp Hinglish, Twilio Voice IVR, Human Escalation, Silent API Retries).
- **Upstream Dependencies**: Policy Orchestrator Context (`DispatchRequest`).

### 4. Payment Integration Context ([src/payment_client.py](./src/payment_client.py) & [src/interfaces.py](./src/interfaces.py))
- **Domain Responsibilities**: REST API communication (Payment Links, Virtual Accounts, Subscriptions), HMAC-SHA256 signature verification.
- **Shared Kernel**: `src/interfaces.py` (`IPaymentLinkGenerator`, `IVirtualAccountGenerator`, `ISubscriptionManager`, `IWebhookVerifier`).

### 5. Audit Ledger Context ([src/ledger.py](./src/ledger.py))
- **Domain Responsibilities**: Immutable, append-only SHA-256 cryptographic chain, single-block proof verification (`verify_block_proof()`).
- **Upstream Dependencies**: Policy Orchestrator Context (`record_entry()`).

### 6. API Boundary & Webhook Gateway Context ([app.py](./app.py))
- **Domain Responsibilities**: FastAPI routes (`/webhook/payment`, `/api/v1/mode`, `/api/v1/ledger/audit/{log_id}`, `/api/v1/entity/{entity_id}/ssot`, `/api/v1/replay`, `/api/v1/operator/reject`), defense-in-depth HMAC verification, lifespan disposability.
